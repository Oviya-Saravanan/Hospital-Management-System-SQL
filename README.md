# 🏥 Hospital Management System

## About the Project

The Hospital Management System is a database project developed using **MySQL** to manage and organise hospital records in an efficient way. The main purpose of this project is to replace manual record-keeping with a structured database that stores all important hospital information in one place.

The system maintains details about patients, doctors, departments, nurses, rooms, appointments, admissions, medicines, prescriptions, laboratory tests, bills, and payments. By connecting these tables through relationships, the database ensures that information is accurate, consistent, and easy to retrieve whenever required.

This project helped me understand how relational databases work and how SQL can be used to solve real-world problems. It also improved my knowledge of database design, relationships, and writing SQL queries.

---

## Features

- Manage patient information
- Store doctor and nurse details
- Schedule patient appointments
- Record patient admissions and room allocation
- Manage medicines and prescriptions
- Store laboratory test records
- Generate bills and payment details
- Retrieve information using SQL queries
